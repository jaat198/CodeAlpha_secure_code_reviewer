# CodeAlpha_secure_code_reviewer

## 🛡️ Task 1: Phishing Awareness Training Web App

### Description
An interactive, full-featured web module designed to train users on identifying social engineering tactics, recognizing fake URLs/domains, and spotting malicious email headers.

### Features
- **Learning Modules:** Detailed guides on Spear Phishing, Smishing, Vishing, and Red Flags.
- **Interactive Email Simulator:** Practice inbox allowing users to analyze headers, inspect links, and reveal security breakdowns for real vs. fake emails.
- **Evaluation Quiz:** Knowledge assessment test with immediate answer feedback.
- **Completion Certificate:** Printable and downloadable completion certificate generated upon passing score.

### How to Run
```bash
# Launch Flask Web Server
py phishing_awareness/app.py
```
Open your browser and navigate to: `http://127.0.0.1:5000`
